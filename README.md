## Sobre mí

Soy un perfil en formación y crecimiento dentro del análisis de datos, con enfoque en transformar información en insights que apoyen mejores decisiones.

Actualmente desarrollo mi portafolio profesional como **Data Analyst**, integrando proyectos de análisis, visualización de datos y comunicación de resultados con herramientas como:

- SQL y PostgreSQL para consultas, limpieza y transformación de datos.
- Power BI para dashboards, KPIs y visualización ejecutiva.
- Excel para análisis tabular, reportes y exploración de datos.
- Storytelling con datos para comunicar hallazgos de forma clara.
- Git y GitHub para documentar proyectos y versionar mi aprendizaje.
